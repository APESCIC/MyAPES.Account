# Release notes and roadmap

**Audience:** everyone

- Change log in the app: [https://myaccount.myapes.me.uk/change-log](https://myaccount.myapes.me.uk/change-log)
- How releases are authored: per-version JSON in `changelog/releases/vX.Y.Z.json` in the repository (`php artisan myapes:changelog-prepare`; sync with `php artisan myapes:releases-sync` on deploy). Not editable in Admin.
- GitHub releases: https://github.com/APESCIC/MyAPES.Account/releases
- Milestones (roadmap): https://github.com/APESCIC/MyAPES.Account/milestones
- Release announcements: [Releases and deploys](https://github.com/APESCIC/MyAPES.Account/discussions/categories/releases-and-deploys)

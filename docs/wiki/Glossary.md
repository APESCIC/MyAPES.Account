# Glossary

**Audience:** everyone  
**Purpose:** terms used in the app and code, including Core versus Account naming.

The full glossary lives in the repository so it changes with the code: [docs/glossary.md](https://github.com/APESCIC/MyAPES.Account/blob/main/docs/glossary.md).

Short version:
- **Core**: the shared base of the app (sign-in, people, settings).
- **Module**: an organisation area: APES CIC, Pet Care Clinic, Shelter and Rescue.
- **Plugin**: a reusable feature used by modules: tickets, pet profiles, cases, recruitment, consultations.
- **MyAPES Account**: the product name people see.
